# Мини-визитка разработчика

Учебный проект по курсу «Full-stack разработка», занятие 1: HTML, CSS и JavaScript.

## Что внутри
- `index.html` — структура страницы (заголовок, «Обо мне», список, картинка, ссылка, форма, карточки)
- `style.css` — оформление, Flexbox-карточки, hover-эффект, светлая и тёмная темы
- `script.js` — кнопка с счётчиком кликов, смена темы, приветствие по имени из формы

## Запуск
Откройте `index.html` в браузере. Установка не нужна.
